# StaffTrack – Employee Management System

StaffTrack is a simple **employee management system** built with PHP, MySQL, HTML, CSS, and JavaScript. It allows HR users to **register, log in, create employees, edit their details, and view employee profiles**.

The system is designed to provide HR managers with an easy way to **organize employee records**, manage departments, and assign roles.

## Features

User Authentication

  * HR can **sign up, log in, and log out** securely.
  * Only HR users can access employee management pages.

Employee Management

  * Add new employees with their **name, department, role, and linked HR user ID**.
  * Edit employee details.
  * View employee profile information.

Departments

  * Employees can be assigned to departments such as **Human Resources, Finance, Operations, and Sales**.

Dashboard

  * HR users can see a summary of employees.

Security

  * Passwords are stored securely.
  * Session-based authentication ensures restricted access.


## How It Works

1. **HR Signup** – A new HR user creates an account.
2. **Login** – The HR logs in using their credentials.
3. **Dashboard** – After login, the HR can manage employees.
4. **Create Employee** – HR can fill a form to add a new employee, and their user ID is automatically stored.
5. **Edit Employee** – Existing employees can be updated.
6. **Employee Profile** – HR can view details of each employee.
7. **Logout** – Ends the session securely.


## Technologies Used

* **PHP** – Server-side scripting for logic and database interaction.
* **MySQL** – Stores HR and employee records.
* **HTML/CSS** – Frontend design and styling.
* **JavaScript** – Client-side validation.
